# Naming Ceremony Invitation

A responsive single-page digital invitation website for a baby's naming ceremony, built with React and Vite.

## ✨ Features

- Elegant invitation landing page
- Hero section with baby photo and event details
- Countdown timer
- Event schedule
- Venue and Google Maps integration
- Wishes section
- Send wishes form
- Embedded invitation video
- Decorative watercolor elements and animations
- Smooth scroll-reveal animations
- Responsive layout

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- HTML
